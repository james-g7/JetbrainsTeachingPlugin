# HTBXIII Learning Agent Tools Changelog

## [Unreleased]

### Added

- Highlight a line, a block of lines or an exact column range in any project file.
- Explanation boxes rendered in the editor directly above highlighted code, with Markdown, hints,
  answers and guided "Next"/"Back" tours.
- Linked explanation trees loaded from JSON, with explanations generated on demand by an
  `ExplanationProvider` when the learner follows a link to one that doesn't exist yet.
- Step-by-step function walkthroughs showing variable values, the call stack and program output,
  played from JSON or generated by a `WalkthroughProvider`.
- **Tools → Learning Agent** menu to try everything by hand.
